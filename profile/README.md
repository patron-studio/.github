# Patron Studio

Patron Studio is a creative studio building web, ecommerce, and marketing
tooling for client brands.

This GitHub organisation hosts our internal tooling, client platform code,
and the shared design / engineering systems that power them.

## Shared systems

- **patron-sales-dashboard** — multi-tenant sales analytics and creative-ops
  dashboard that every client brand logs into. Includes the Emailer, our
  email marketing toolkit (block-based composition, live preview, export to
  Mailchimp / Klaviyo).
- **patron-ui** — shadcn-style component registry (charts, overlays, forms)
  used across client sites and internal tools.
